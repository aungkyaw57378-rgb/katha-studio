# Katha Studio

Free AI video maker for Android (installable from Chrome). Type an idea, pick a length and language (English, Nepali, Burmese, Thai, Hindi), and the app writes the script, records a neural voice, finds photos and records a captioned video on your phone.

- Script: Google Gemini free tier (your own key, kept on your phone)
- Voice: Microsoft Edge neural voices through this server (`/api/tts`)
- Photos: Pexels (your own free key) or Wikimedia Commons
- Video: recorded in the browser with canvas + MediaRecorder

Run locally: `npm install && npm start`
